# Kit-Smith-Menu-Management-System
An enterprise menu engineering and procurement system built with Python, SQL, and React.

## Running the app
From the repository root:

    pip install -r requirements.txt
    python server.py

Then open http://127.0.0.1:5000/ — the Main Menu (Item, Recipe, Purchasing, Inventory) is the home page.
Run `server.py` (not `src/app.py`, which is a console cost report). Make sure you have the latest code (`git pull`) and restart the server after updating.
